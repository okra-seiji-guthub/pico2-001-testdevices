# Hz と周期（秒・ミリ秒）対応表

周波数 **Hz**（1 秒あたりの回数）と、1 周期あたりの時間の換算です。

## 基本式

| 求めたいもの | 式 |
|--------------|-----|
| 周期（秒） | \(T = 1 / f\) |
| 周期（ミリ秒） | \(T_{\mathrm{ms}} = 1000 / f\) |
| 周波数（Hz） | \(f = 1 / T\) |
| 周波数（Hz） | \(f = 1000 / T_{\mathrm{ms}}\) |

マイクロ秒: \(T_{\mu\mathrm{s}} = 10^{6} / f = 1000 \times T_{\mathrm{ms}}\)

表中の μs・ms は有効数字を揃えた概算です。実装では `1000 // hz` や `1_000_000 // hz` で整数演算するとよいです。

## ログの μs を読むとき

ターミナルに `292977us` と出た場合:

- **292977 μs** = **292.977 ms** ≈ **0.293 s**（3 秒ではない）
- 相当する平均レート: \(1000 / 292.977 \approx 3.4\) Hz（そのループが 1 回あたり約 0.3 秒）

## MicroPython の例

```python
HZ = 240
period_ms = 1000 // HZ          # 4
period_us = 1_000_000 // HZ     # 4166

# ループを目標周期に揃える（処理時間を引く）
LOOP_US = 1_000_000 // HZ
start = time.ticks_us()
# ... work ...
rest = LOOP_US - time.ticks_diff(time.ticks_us(), start)
if rest > 0:
    time.sleep_us(rest)
```
