# ハードウェア構成（電源・ピン・基板）

TC78H653FTG 導入に向けて決めたハード構成のメモ。実装は [tc78h653-plan.md](./tc78h653-plan.md)、ソフト構成は [system-architecture.md](./system-architecture.md) を参照。

## 電源

| 系統 | 電池 | 供給先 |
|------|------|--------|
| モーター兼サーボ | 単3 × 4 | TC78H653FTG の VM、サーボの + |
| Pico | 単4 × 3（検討中。単4 × 2 も候補） | Pico の VSYS |

- **GND は全部共通**（Pico・ドライバ・サーボ・両電池パック）。モーターの大電流の戻りは、Pico / IMU の GND と一点で合流させる。
- **サーボは Pico 側から給電しない**。サーボの信号線だけ GPIO に繋ぎ、+ はモーター側の電池から取る。Pico の 3V3 ピンから取るのも不可。
- 単4 × 2 は新品で約 3.0V、使うと 2V 台まで下がる。サーボ（SG90 は 4.8〜6V）には不足する。
- 単4 × 3 は、アルカリ新品で約 4.5〜4.8V、ニッケル水素で約 3.6〜3.9V。Pico の VSYS 入力（1.8〜5.5V）に余裕で収まる。
- 単3 × 4 は、アルカリ新品で約 6.0V、ニッケル水素で約 4.8〜5.6V。TC78H653FTG の VM 上限（約 7V）とサーボの上限（6V）以内。大電流ではアルカリ単3 の電圧が大きく下がるので、モーターが 1A を超えるならニッケル水素が安定する。
- 電池ボックスは直列本数が合うものを選ぶ（単3 × 4 を、別の本数と取り違えない）。

### LiPo(2S) を使う場合
直結は**不可**（満充電 8.4V が VM 上限約 7V・サーボ 6V・VSYS 5.5V を超える）。使うなら降圧する。

```
2S LiPo ── (ヒューズ/スイッチ) ─┬─ 降圧 6V (3A 以上) ─ モーター VM + サーボ
                                └─ 降圧 5V (小) ───── Pico (VSYS)
```

- 降圧レギュレータはモーターの逆起電力を吸えないので、出力側にコンデンサを付ける。
- 過放電（3.0V/セル未満）と短絡に弱い。低電圧カットとヒューズが必須で、専用のバランス充電器が要る。
- 当面は乾電池で進める。基板化のときに降圧モジュール用のパッドとジャンパを用意しておき、後から移行できるようにする。

## USB 給電でのベンチ構成

- Pico は PC の USB から給電する。
- モーターとサーボは単3 × 4 の電池パックから給電する。GND は共通にする。電池パックの + を VBUS や VSYS に繋がない。
- VBUS から取らないのは**モーター**。PC の USB は 500mA までで、始動・ロック時に 1〜2A 級を引くと USB が遮断されるか、Pico がリセットされる。
- **サーボ単体**の動作確認なら VBUS（物理ピン 40）から取ってもよい。ただし無負荷（リンクを外した状態）で、VBUS と GND の間に 100〜470µF を付ける。ロックすると約 650mA 流れ、USB が落ちる。
- 車に載せてステアリングを切るときは、単3 × 4 から給電する。

## ピン割り当て

IMU 等のモジュールは Pico の左側、サーボと TC78H653FTG は右側にまとめる。モーターのノイズが乗りやすい配線を IMU から離せる。

| 側 | 用途 | GP | 物理ピン |
|----|------|----|----------|
| 左 | I2C0（IMU・ToF）SDA / SCL | GP8 / GP9 | 11 / 12 |
| 左 | I2C1（OLED）SDA / SCL | GP10 / GP11 | 14 / 15 |
| 左 | 外付け LED | GP15 | 20 |
| 右 | TC78H653FTG の IN1 | GP16 | 21 |
| 右 | TC78H653FTG の IN2 | GP17 | 22 |
| 右 | サーボ信号 | GP18 | 24 |

- 物理ピン 23 番が GND で、GP17 と GP18 の間にあるので、サーボの GND に使いやすい。
- TC78H653FTG の MODE などの制御ピンを GPIO から駆動する場合は、右側の GP19〜GP22（物理ピン 25〜27, 29）を使うと同じ側にまとまる。
- Pico 2 W の GP23〜25 と GP29 は Wi-Fi・電源用で、ピンとして出ていない。**`Pin()` に渡すのは GP 番号**で、物理ピン番号とは別。

### PWM スライス
PWM は 2 ピンずつ 1 つの**スライス**にまとまり、スライス内は周波数が共通（デューティだけ別）。スライス番号は `GP ÷ 2`（小数切り捨て）。

| ピン | スライス | 周波数 |
|------|----------|--------|
| GP16, GP17（IN1, IN2） | 0 | 20 kHz |
| GP18（サーボ） | 1 | 50 Hz |

**周波数が違うものは別スライスに置く。**

### 現状のコードとの差
- 現状の `config.py` の既定値は `ESC_PIN = 16`、`SERVO_PIN = 17`。ESC 出力を使う間はこのままでよい（どちらも 50Hz なら同一スライスで問題ない）。
- サーボを GP18 にするには、Pico 側の `config_local.py`（git 管理外）に次を足す。

```python
SERVO_PIN = 18
```

- TC78H653FTG への移行時に、IN1/IN2 = GP16/GP17、サーボ = GP18 を既定値にする。

## サーボの配線

| 線 | 接続先 |
|----|--------|
| 黄（または橙）: 信号 | GP18 |
| 赤: + | 単3 × 4 の +（ベンチでサーボ単体を試すときは VBUS） |
| 茶: GND | GND（Pico と電池パックで共通） |

SG90 の色分け。RG50 は色の並びが違う可能性があるので、データシートかコネクタの刻印で確認する。

## まとめ基板

Pico とは別に、周辺をまとめた基板を作る。**ユニバーサル基板やブレッドボードで試作して動作を確認してから、KiCad で設計・発注する。** TC78H653FTG の真理値表とピン割り当てが未確定なので、先に基板化すると作り直しになるおそれがある。

### 載せるもの
- Pico（メス型ピンヘッダで、取り外せるようにする）
- TC78H653FTG モジュール用ヘッダ
- サーボ用の 3 ピンヘッダ（2.54mm）
- モーター出力 2 ピン
- 電源 2 系統（モーター兼サーボ用、Pico 用）。それぞれスイッチ付き
- I2C 4 ピン（3V3 / GND / SDA / SCL）× 2 系統
- 外付け LED 2 ピン × 4

コネクタは、電池ボックスの線が裸線ならネジ端子台が楽。I2C と LED は JST-XH などの 2.54mm ピッチにそろえる。

### 入れておく部品・設計
- 電源の**逆接続保護**（ダイオードか P-MOSFET）
- VM とサーボ電源の近くに **100〜470µF**
- **一点接地**。IMU はモーターから離して置く
- 電池を VSYS に直結する場合は、USB と同時に挿した逆流を防ぐ**低 Vf のショットキーダイオードか理想ダイオード回路**（電池が 2.4〜3V 台と低く、通常のダイオードでは降下が効く）
- モーター側は 2A 級を想定して配線を太くする
